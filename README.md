# Git Instruction Workshop

A structured workshop outline covering Git and collaborative development from first principles to pull requests.

## Workshop topics

1. What version control is and why it matters
2. Installing Git and VS Code
3. Creating and working with local repositories
4. Understanding and using branches
5. Working with remote GitHub repositories
6. Collaborative workflows
7. Creating pull requests
8. Recommended books and learning resources
9. Alternative version-control systems
